# Лог проекта HHParser

## Текущее состояние — 2026-09-21

Репозиторий содержит исходные скрипты сбора и разбора резюме, CSV-датасеты и отдельную заготовку чата с ЛЛМ.

### Основные файлы репозитория

- `collect_links.py` — сбор ссылок на резюме.
- `parse_resumes.py` — обработка резюме.
- `resume_links.csv`, `resumes_dataset.csv`, `resumes_dataset_1.0.csv` — исходные данные и результаты обработки.

### Чат с ЛЛМ

В директории `llm_chat` находятся:

- `server.py` — локальный сервер на Python без внешних зависимостей.
- `index.html` — веб-интерфейс чата.
- `README.md` — инструкция по запуску.

Чат принимает сообщения через `POST /api/chat` и пока отвечает ошибкой:

> Сейчас пока ничего не работает, но скоро будет.

### Запуск и проверка

Запуск из корня репозитория:

```bash
python llm_chat/server.py
```

Адрес интерфейса: `http://127.0.0.1:8000`.

Проверен запуск сервера и успешный POST-запрос к `/api/chat`.
